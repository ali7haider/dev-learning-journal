# What is Node JS?
Node Js is javascript runtime environment that allows you to run the javascript code outside the browser(server or pc).
We can think Node of Engine that runs Javascript code.
with node js we can build 
- Servers
- APIs
- Backend Services
- Command-line tools

# What is NPM?
NPM is package manager that comes with node js that allows you to install, share and manage libraries for your node projects
- simple words allows to manage libraries
